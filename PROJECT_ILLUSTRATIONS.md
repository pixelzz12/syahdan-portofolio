# Original project sketch assets

Five original concept illustrations were generated with the built-in imagegen tool for the project entries. They are illustrative placeholders, not screenshots or proof of implemented functionality. No reference-site artwork, project names, descriptions, logos, or application screenshots were imported. Authentic screenshots take priority whenever configured in `src/data/portfolio.ts`.

Generated PNG originals remain in the Codex generated-images folder and are copied to ignored `assets/source/projects/<id>-sketch-v1.png`. Public WebP derivatives are `public/assets/illustrations/<id>-sketch-v1.webp` (1200px maximum width, quality 88) and `<id>-sketch-thumb-v1.webp` (600px maximum width, quality 84). Resizing preserves the full image and its aspect ratio.

## Exact shared prompt

Use case: stylized-concept. Asset type: ONE landscape 4:3 project illustration for the screen of a stylized industrial 3D portfolio monitor. Original hand-drawn graphite pencil and soft gouache illustration on warm cream paper, sketchbook grain, confident imperfect outlines, delicate cross-hatching, restrained muted teal and ochre accents. Close flat readable composition of a conceptual interface with small physical design props. No monitor housing or external device frame (the application supplies the 3D frame). No people, no logos, no branding, no watermark, no finished-project claim, no dates, no achievement, no real screenshot. This is explicitly an illustrative placeholder for an unfinished or undocumented project, not evidence of its functionality. Avoid readable UI text; use quiet abstract labels and lines. Do not imitate or reproduce reference-site artwork. Fill most of the canvas with the topic; make it appealing and legible at small size.

Each request appended its corresponding topic below. These were four independent generation calls, one per illustration. The personal-portfolio result includes an abstract illustrated avatar placeholder inside its fictional interface; this is not the owner's portrait and is not used as a profile image.
